## API Key Errors

### Error: `openai.AuthenticationError`

**Cause**: Invalid or missing API key

**Solution**: 
- Check `.env` file contains `OPENAI_API_KEY=sk-proj-...`
- Verify key doesn't have spaces/tabs
- Ensure `load_dotenv()` is called

**Prevention**: Use troubleshooting notebook to diagnose
